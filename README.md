# coding-probtheory

This is the public repository for the DSC Capstone Domain focused on developing simulation-based coding exercises to help students learn and understand probability concepts.

The exercises are provided as Jupyter notebooks and can be run using  [MyBinder](https://mybinder.org/) without installing anything locally.

There are two ways to open the notebook:

### Method 1: Manually Open a Notebook Through MyBinder

1. Go to [MyBinder](https://mybinder.org/).
2. Under **GitHub repository name or URL**, enter:
   ```
   https://github.com/peterbchi/coding-probtheory
   ```
3. Under **File to open (in JupyterLab)**, enter the path to the notebook you want to open.
4. Click **Launch** to open the notebook.

**Example: Chebyshev's Inequality**

To open the Chebyshev's Inequality notebook, input:

- **GitHub repository name or URL:** `https://github.com/peterbchi/coding-probtheory`
- **File to open (in JupyterLab):** `Chebyshev/Chebyshev_Exercises.ipynb`
